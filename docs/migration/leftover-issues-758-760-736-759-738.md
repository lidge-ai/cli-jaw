# Leftover issue contracts (#758 #760 #736 #759 #738)

Public lock for the five open issues after `cli-jaw@2.17.53` / [#761](https://github.com/lidge-jun/cli-jaw/issues/761). This page is the contract, not a claim that the code has landed.

| Issue | Contract |
| --- | --- |
| [#758](https://github.com/lidge-jun/cli-jaw/issues/758) | `channels.slackScopes.ok` is true when the grant was observed and `missingRequired` is empty. Optional `missingCapabilities` (including `mpim:history`) stay visible and do not fail `ok`. |
| [#760](https://github.com/lidge-jun/cli-jaw/issues/760) | Slack journaled events settle. Health `processing` is in-flight admits only. `oldestOpenReceivedAt` ignores `completed` and `dead_letter`. Stale `processing` is abandoned by age at journal boot, not by a process-wide `session_generation`. |
| [#736](https://github.com/lidge-jun/cli-jaw/issues/736) | `runtimeStatus` stays `stopped`. `orchestrate_done` carries `stopCause` (`watchdog` / `user_stop` / `steer_kill`) so channel finals use three sentences. Missing cause keeps `tg.stopped`. |
| [#759](https://github.com/lidge-jun/cli-jaw/issues/759) | Exit 130 with no kill reason is `stopCause: unattributed`, not a Jaw kill. No invented `[jaw:kill]` line. |
| [#738](https://github.com/lidge-jun/cli-jaw/issues/738) | Pi gets a `NativeRuntimeSession` adapter, abort-then-kill `cancel()`, and employee acquire/send split. `interrupt` vs worker-slot clear stays open unless evidence decides it. |

Implementation lands on `dev` in later cycles. This file does not change runtime behavior.
