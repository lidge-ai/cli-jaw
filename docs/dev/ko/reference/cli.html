CLI 명령어

CLI-JAW는 채팅 인터페이스의 슬래시 명령어와 터미널에서 사용할 수 있는 26개의 루트 라우터 케이스, 그리고 chat search, browser web-ai, dashboard memory/chat search 같은 그룹형 CLI 표면을 제공합니다.

루트 CLI 하위 명령어

터미널에서 jaw <command> 형식으로 직접 실행합니다:

명령어설명
jaw serve단일 인스턴스 서버 시작
jaw dashboard다중 인스턴스 대시보드 시작
jaw init대화형 설정 마법사
jaw doctor설치 상태 진단
jaw status서버 상태 확인
jaw chat터미널 REPL
jaw dispatch직원 작업 디스패치
jaw employee직원 관리
jaw orchestratePABCD 상태 머신
jaw goal목표 생명주기 관리
jaw memory메모리 검색/읽기/저장
jaw browserChrome CDP 브라우저 제어
jaw skill스킬 관리
jaw mcpMCP 서버 관리
jaw service시스템 서비스 관리
jaw clone인스턴스 복제
jaw connector대시보드 커넥터
jaw reminders리마인더 관리
jaw project프로젝트 디렉토리 관리
jaw reset설정 초기화

슬래시 명령어 (채팅 인터페이스)

채팅 입력창에서 / 접두사를 붙여 입력합니다:

세션

명령어인수설명
/help도움말 표시
/commands모든 명령어 목록
/status세션 상태
/clear채팅 기록 지우기
/compact컨텍스트 압축
/reset[scope]세션 초기화

워크플로우

명령어인수설명
/plan[task]구현 계획 생성
/interview[request]요구사항 명확화 (1-3개 질문)
/deliberate[topic]심층 추론
/planaudit[plan]계획 감사
/goal<sub>목표 관리 (set/done/cancel/...)
/team<sub>병렬 팀 오케스트레이션

모델

명령어인수설명
/model[name]AI 모델 전환
/cli[name]CLI 런타임 전환
/fallback[provider]폴백 프로바이더 설정
/forward[provider]프로바이더로 전달
/thought[toggle]확장 사고 토글
/flush대기 중인 출력 플러시

도구

명령어인수설명
/skill[sub]스킬 관리
/employee[sub]직원 관리
/mcp[sub]MCP 서버 관리
/memory[query]메모리 검색
/browser[sub]브라우저 제어
/orchestrate[phase]PABCD 오케스트레이션
/project[sub]프로젝트 설정
