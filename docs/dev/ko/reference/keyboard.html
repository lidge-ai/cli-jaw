키보드 단축키

CLI-JAW Electron 데스크톱 앱을 위한 IDE 스타일 키보드 단축키입니다.

이 단축키는 Electron 데스크톱 앱에서만 사용할 수 있으며, 웹 브라우저 UI에서는 사용할 수 없습니다.

탭 관리

단축키동작
Cmd+W포커스된 탭 닫기 (브라우저/터미널/사이드바). 앱은 계속 열려 있습니다.
Cmd+1Overview 탭으로 전환
Cmd+2Preview 탭으로 전환
Cmd+3Logs 탭으로 전환
Cmd+Shift+[이전 탭
Cmd+Shift+]다음 탭

패널

단축키동작
Cmd+B오른쪽 사이드바 토글
Cmd+Shift+B왼쪽 사이드바 (인스턴스) 토글
Cmd+J하단 패널 토글
Cmd+Shift+E폴더 패널 열기
Cmd+Shift+Ddiff 패널 열기
Ctrl+Shift+`터미널로 포커스 이동

브라우저 패널

단축키동작범위
Cmd+LURL 바로 포커스 이동브라우저 포커스 시
Cmd+R페이지 새로고침브라우저 포커스 시
Cmd+Shift+R강력 새로고침브라우저 포커스 시
Cmd+Left뒤로 이동브라우저 포커스 시
Cmd+Right앞으로 이동브라우저 포커스 시

터미널

단축키동작범위
Cmd+K터미널 버퍼 지우기터미널 포커스 시
Cmd+T새 터미널 탭터미널 포커스 시

확대/축소

단축키동작
Cmd+=확대
Cmd+-축소
Cmd+0확대/축소 초기화
