칸반 보드

내장된 칸반 보드는 표준 워크플로 레인을 사용한 작업 관리를 제공합니다. Dashboard의 Board 탭에서 접근할 수 있습니다.

워크플로 레인

작업은 다음 레인을 통해 진행됩니다:

레인용도
Backlog시작 대기 중인 작업
Ready준비가 완료되어 착수 가능한 작업
Active현재 진행 중인 작업
Review완료되어 검토 대기 중인 작업
Done완료된 작업

카드 조작

  • 생성 -- 원하는 레인에 새 카드를 추가합니다
  • 편집 -- 카드의 제목, 설명, 메타데이터를 수정합니다
  • 이동 -- 카드를 레인 간에 드래그하거나 레인 내에서 순서를 변경합니다
  • 삭제 -- 보드에서 카드를 제거합니다

보드 API

메서드경로설명
GET/api/dashboard/board/tasks모든 작업 목록 조회
POST/api/dashboard/board/tasks작업 생성
PATCH/api/dashboard/board/tasks작업 수정 (이동, 편집)
DELETE/api/dashboard/board/tasks작업 삭제

CLI 접근

# Add a task
jaw connector board add "Implement user auth" --lane backlog

# Update a task
jaw connector board update <id> --lane active

# List tasks
jaw connector board list

향후 계획: 인스턴스 동기화

향후 버전에서는 보드 작업을 인스턴스 오케스트레이션 상태와 동기화하는 기능을 지원할 예정이며, PABCD 단계가 자동으로 보드 카드를 생성하고 이동할 수 있게 됩니다.
