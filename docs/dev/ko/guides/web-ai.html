웹 AI

CLI-JAW는 브라우저 탭 관리를 통해 ChatGPT, Gemini, Grok 웹 인터페이스를 자동화할 수 있으며, API 키 없이도 에이전트가 여러 AI 제공자를 사용할 수 있게 합니다.

개요

웹 AI는 CDP (Chrome DevTools Protocol)를 사용하여 브라우저 탭을 제어합니다. 에이전트는 ChatGPT, Gemini, Grok의 웹 UI를 통해 프롬프트를 전송하고 응답을 다시 읽어올 수 있습니다.

설정

jaw browser start --agent    # Start CDP browser
jaw browser status           # Check connection

탭 풀

CLI-JAW는 모든 요청마다 새 탭을 열지 않도록 브라우저 탭 풀을 유지합니다. 탭은 세션 간에 재사용되며, 고아 탭은 자동으로 정리됩니다.

명령어

/browser web-ai send "prompt"    # Send to active provider
/browser web-ai poll             # Poll for response
/browser web-ai sessions         # List active sessions

agbrowse

agbrowse 스킬은 에이전트가 API 제한에 도달하거나 추가 의견이 필요할 때 웹 AI 제공자에게 질문을 위임할 수 있게 합니다.
