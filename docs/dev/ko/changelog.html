변경 이력

CLI-JAW 2.0.0 GA 이후 릴리스 히스토리입니다.

미출시 — 2026-06-28

수정

  • Manager UI 경계 — Worker progress monitor가 인스턴스별 Jaw 사이드바에 더 이상 렌더링되지 않습니다. Code/CEO 런타임 관측은 전용 Code lane에만 남습니다.
  • Watchdog 진단 — 턴이 멈출 때 idle/progress watchdog 종료 사유가 Telegram에 표시됩니다.

v2.2.3 — 2026-06-27

릴리스

  • GitHub OIDC Trusted Publishing과 데스크톱 asset 파이프라인을 포함한 stable npm latest 릴리스.
  • v2.2.2 라인의 Telegram Hub P4 강화, AGY capability-probe 게이팅, goal pause gate 문서 동기화, release-gate CI 정렬을 포함합니다.

v2.2.2 — 2026-06-25

수정

  • Dashboard Notes: bare .md 파일명이 더 이상 Jawsidian 라우트로 자동 하이퍼링크되지 않습니다.
  • Adaptive-fetch deadline 취소가 browser/CDP 단계까지 확장되었습니다.

기능

  • /skill:<id> 슬래시 커맨드가 CLI/Web에서 활성 런타임 스킬을 노출합니다.
  • 개발자 문서 skills catalog가 live registry에서 재생성되었습니다.

v2.2.1 — 2026-06-23

기능

  • 외부 JWC 런타임 헬퍼 (jaw jwc install|doctor|clean) — 선택 사항, npm/Electron에 번들되지 않음.
  • Adaptive URL fetch (jaw browser fetch) P0 갭 종료: SSRF 가드, warm browser pool, BM25 필터, Camoufox stealth, yt-dlp reader.
  • skills_ref/에서 기본 스킬 자동 활성화 (search, goal, structured-renderers 등).
  • Worker progress monitor API와 manager runtime-status bridge.

v2.2.0 — 2026-06-22

기능

  • 통합 release branch 정책과 강화된 release-gate CI 계약.
  • Strict TypeScript interop 경계를 테스트에 명시.

v2.1.5 — 2026-06-15

데스크톱

  • macOS/Windows/Linux CI matrix에서 Electron desktop shell 검증.
  • 서명되지 않은 desktop asset 배포 문서화; npm 패키지는 CLI 전용 유지.

v2.1.3 — 2026-06-04

기능

  • Goal heartbeat, workflow scope 제어, manager polish.
  • Electron native file-drop을 활성 workspace로 라우팅.

v2.0.17 — 2026-05-29

기능

  • IDE 키보드 단축키: Cmd+W 탭 닫기, Cmd+1-4 탭 전환, Cmd+Shift+[/] 탭 이동
  • 브라우저 패널 단축키: Cmd+L (URL), Cmd+R (새로고침), Cmd+Shift+R (강제 새로고침), Cmd+Left/Right (뒤로/앞으로)
  • 터미널 단축키: Cmd+K (지우기), Cmd+T (새 탭)
  • Cmd+Shift+B로 왼쪽 사이드바(인스턴스) 토글
  • 오른쪽 패널 너비 제한 제거 -- 자유롭게 확장 가능
  • cli-jaw goal CLI 하위 명령어 (set/status/done/cancel/update/history)
  • Goal 연속 실행이 PABCD 단계에서도 발동

수정

  • Electron 권한 정책: 기본 허용 + 안전 차단 목록 방식으로 변경
  • 미리보기 권한 알림 제거 ("background-sync blocked" 메시지 해소)
  • 프론트엔드 tsc 타입 안전성: PanelBusAction 유니온 적용
  • 포커스 범위 단축키 (브라우저/터미널 동작은 해당 영역에 포커스될 때만 실행)
  • PanelLayoutProvider 오래된 클로저 수정
  • Cmd+K 충돌 해결 (CommandPalette 유지, 메뉴 가속키 제거)
