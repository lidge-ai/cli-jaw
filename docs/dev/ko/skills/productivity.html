Productivity Skills

문서 생성, 지식 관리, 작업 추적, 메모 작성, 한국어 콘텐츠 작성 관련 스킬입니다. 이 17개 스킬은 CLI-JAW를 오피스 제품군, 프로젝트 관리 도구, 개인 생산성 앱, 편집 워크플로와 연결하여 채팅 인터페이스에서 문서, 작업, 콘텐츠를 생성, 읽기, 편집, 정리할 수 있게 해줍니다.

Overview

생산성 스킬은 다섯 그룹으로 나뉩니다: 문서 형식(Office 및 HWP 파일 입출력), 지식 관리(Notion, Obsidian, Apple Notes), 작업 관리(Things, Reminders, Trello, Linear), 협업 유틸리티(공동 작성, HTML-to-PPTX 변환), 콘텐츠 작성(k-writing을 통한 한국어 홍보/편집 출력).

Document Skills

네 가지 문서 스킬(docx, pptx, xlsx, hwp)은 모두 현재 활성 상태이며 각 형식에 대한 완전한 읽기/쓰기/편집 기능을 제공합니다.

docx -- Word Documents

구조화된 콘텐츠 블록을 사용하여 .docx 파일을 생성하고 편집합니다. 제목, 단락, 표, 글머리 기호 목록, 이미지, 사용자 정의 스타일을 지원합니다.

# Create a new Word document
"프로젝트 보고서를 docx로 만들어줘"

# Read and summarize an existing document
"이 docx 파일 읽어서 요약해줘"

# Edit specific sections
"3번째 섹션의 표를 업데이트해줘"

pptx -- PowerPoint Presentations

레이아웃, 텍스트 상자, 이미지, 차트, 발표자 노트가 포함된 슬라이드 덱을 생성합니다. 마스터 슬라이드 템플릿과 사용자 정의 테마를 지원합니다.

# Create a presentation from scratch
"PPT 만들어줘 -- 10장짜리 프로젝트 발표용"

# Add slides to existing presentation
"이 PPT에 요약 슬라이드 추가해줘"

# Convert content to slides
"이 마크다운을 PPT로 변환해줘"

xlsx -- Excel Spreadsheets

수식, 차트, 조건부 서식, 피벗 테이블, 다중 시트가 포함된 스프레드시트를 생성하고 조작합니다.

# Create a budget spreadsheet
"월별 예산 엑셀 만들어줘"

# Analyze existing data
"이 엑셀 데이터 분석해서 차트 추가해줘"

# Generate report from data
"매출 데이터로 분기별 보고서 엑셀 만들어줘"

hwp -- Korean HWP/HWPX Documents

한컴오피스 HWP 및 HWPX(OWPML) 형식을 완벽하게 지원합니다. 한국어 특화 문서 레이아웃, 표, 서식을 처리합니다. 한글, .hwp, .hwpx, 한컴오피스, OWPML 같은 키워드로 트리거됩니다.

# Read an HWP file
"한글 문서 읽어줘"

# Create an official Korean document
"공문서 양식으로 한글 파일 만들어줘"

# Convert between formats
"이 hwp 파일을 docx로 변환해줘"
Tip: 모든 문서 스킬은 프롬프트에서 언어를 자동 감지합니다. "PPT 만들어줘"나 "한글 문서 읽어줘" 같은 한국어 프롬프트는 영어 명령과 함께 자연스럽게 동작합니다. 스킬이 인코딩, 폰트, 로케일별 서식을 자동으로 처리합니다.

Knowledge Management

이 스킬들은 메모 및 지식 베이스 플랫폼과 연동하여 정보를 수집, 정리, 검색합니다.

notion

핵심 Notion 연동 스킬입니다. 현재 활성 상태입니다. Notion API에 연결하여 페이지 읽기, 새 페이지 생성, 콘텐츠 업데이트, 데이터베이스 조회를 수행합니다.

# Create a page in Notion
"노션에 정리해줘 -- 오늘 회의 내용"

# Query a database
"노션 프로젝트 DB에서 진행중인 태스크 보여줘"

# Update an existing page
"노션 위클리 리포트 페이지 업데이트해줘"

apple-notes (Planned)

AppleScript를 통해 macOS의 Apple Notes와 연동합니다. 폴더별 메모 생성, 검색, 읽기, 추가 기능을 지원할 예정입니다.

# Create a quick note
"애플 노트에 메모 남겨줘: 내일 미팅 준비사항"

# Search notes
"애플 노트에서 지난주 메모 검색해줘"

obsidian (Planned)

Obsidian 볼트와 직접 연동합니다. 마크다운 파일 읽기/쓰기, 태그 관리, 위키링크 생성, 볼트 폴더 구조 준수 기능을 지원할 예정입니다.

# Create a note in Obsidian
"옵시디언에 새 노트 만들어줘: 아키텍처 결정 기록"

# Search vault
"옵시디언 볼트에서 API 관련 노트 찾아줘"

Task Management

작업 관리 스킬은 CLI-JAW를 인기 있는 할 일 및 프로젝트 추적 도구와 연결합니다. 현재 모두 계획 단계입니다.

apple-reminders (Planned)

AppleScript를 통해 Apple Reminders에서 미리 알림을 생성하고 관리합니다. 마감일, 우선순위, 목록, 반복 미리 알림을 지원합니다.

# Add a reminder
"리마인더에 추가해줘: 금요일까지 보고서 제출"

# List today's reminders
"오늘 리마인더 보여줘"

things-mac (Planned)

URL scheme 및 AppleScript를 통한 Things 3 for Mac 연동입니다. 할 일, 프로젝트, 영역 생성 및 태그 관리를 지원할 예정입니다.

# Create a to-do
"Things에 할일 추가해줘: 코드 리뷰"

# Create a project with tasks
"Things에 새 프로젝트 만들어줘 -- 릴리즈 체크리스트"

trello (Planned)

Trello REST API를 통해 Trello 보드, 리스트, 카드를 관리합니다. 카드 생성, 리스트 간 이동, 라벨, 체크리스트, 첨부 파일 추가를 지원할 예정입니다.

# Create a card
"트렐로 보드에 카드 추가해줘: 버그 수정 필요"

# Move a card
"트렐로에서 이 카드를 Done으로 옮겨줘"

linear (Planned)

Linear 프로젝트 관리와의 연동입니다. Linear GraphQL API를 통해 이슈 생성, 상태 업데이트, 프로젝트 조회, 사이클 관리를 지원할 예정입니다.

# Create an issue
"리니어에 이슈 만들어줘: 로그인 페이지 리디자인"

# Query project status
"리니어에서 이번 사이클 진행 상황 보여줘"

Collaboration Utilities

문서 협업 및 형식 변환 워크플로를 위한 특화 스킬입니다.

doc-coauthoring (Planned)

AI가 사람의 입력과 함께 문서 초안 작성, 검토, 다듬기를 지원하는 실시간 협업 문서 편집 기능입니다. 버전 추적, 제안 모드, 코멘트 해결 기능을 지원할 예정입니다.

# Start co-authoring session
"이 보고서 같이 작성하자 -- 내가 개요 쓸 테니 본문 채워줘"

# Review and suggest edits
"이 문서 리뷰하고 수정 제안해줘"

html2pptx (Planned)

HTML 콘텐츠(웹 페이지, 렌더링된 마크다운, 리포트 출력)를 서식이 적용된 PowerPoint 슬라이드로 변환합니다. 리서치 결과나 대시보드 내보내기를 발표용 덱으로 만들 때 유용합니다.

# Convert HTML report to slides
"이 HTML 리포트를 PPT로 변환해줘"

# Web page to presentation
"이 웹페이지 내용을 발표자료로 만들어줘"
Natural language triggers: 스킬 이름을 기억할 필요가 없습니다. 원하는 것을 자연어로 설명하기만 하면 됩니다. 예시:
  • "PPT 만들어줘"는 pptx 스킬을 트리거합니다
  • "노션에 정리해줘"는 notion 스킬을 트리거합니다
  • "한글 문서 읽어줘"는 hwp 스킬을 트리거합니다
  • "엑셀로 정리해줘"는 xlsx 스킬을 트리거합니다
  • "이거 홍보 쓰레드로 써줘"는 active k-writing 스킬을 트리거합니다
  • "리마인더에 추가해줘"는 apple-reminders 스킬을 트리거합니다
  • "트렐로에 카드 만들어줘"는 trello 스킬을 트리거합니다
CLI-JAW가 사용자의 의도를 적절한 스킬에 자동으로 매칭합니다.

Configuration

일부 생산성 스킬은 API 토큰 또는 앱별 설정이 필요합니다. CLI-JAW 설정이나 환경 변수에서 구성하세요.

SkillRequirementConfiguration
notionNotion API 토큰환경 변수 또는 settings.json에 NOTION_API_KEY 설정
trelloTrello API 키 + 토큰TRELLO_API_KEY, TRELLO_TOKEN
linearLinear API 키LINEAR_API_KEY
obsidian볼트 경로설정에서 OBSIDIAN_VAULT_PATH 지정

hwp없음별도 설정 없이 바로 사용 가능
apple-notes / apple-reminders / things-macmacOS시스템 설정에서 AppleScript 접근을 허용해야 합니다

Skill Interactions

생산성 스킬은 다른 CLI-JAW 기능과 자연스럽게 결합됩니다:

  • deep-research + notion: 주제를 리서치하고 결과를 Notion 데이터베이스에 저장
  • xlsx + pptx: 스프레드시트 데이터를 분석하고 차트가 포함된 프레젠테이션 생성
  • hwp + docx: 한국어 HWP와 Word 형식 간 변환
  • k-writing + search: 최신 출처 확인, 훅 채점, AI 티 검토를 거쳐 한국어 홍보 문안 생성
  • notion-meeting + telegram: 회의록을 작성하고 요약을 Telegram으로 전송
  • html2pptx + web-ai: 웹 페이지를 스크래핑하여 슬라이드 덱으로 변환
  • linear + trello: 프로젝트 관리 도구 간 이슈 상태 동기화
