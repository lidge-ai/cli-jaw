Desktop Control Default Active

데스크톱 앱과 브라우저 창 UI에는 Computer Use 도구를, 일반 웹페이지 DOM에는 jaw browser를 사용합니다.

스킬 ID: desktop-control
도구: jaw-computer-use MCP 서버의 js; Codex는 기본 Computer Use 플러그인 사용
호스트: macOS 또는 Codex 데스크톱 플러그인 캐시가 있는 Windows

실행 경로

Computer Use는 직원이 아니라 MCP 도구입니다. Jaw는 Codex를 제외한 MCP 지원 CLI에 jaw-computer-use를 등록합니다. Claude에서는 mcp__jaw-computer-use__js로 표시됩니다. Codex boss와 직원은 Codex 기본 Computer Use 플러그인을 사용합니다. 긴 GUI 작업은 같은 도구가 노출된 직원에게 맡길 수 있지만 특정 Control 직원이 필요하지 않습니다.

웹페이지 DOM은 jaw browser snapshot --interactive의 ref로 조작합니다. 데스크톱 앱 창, 브라우저 창 UI, OS 대화상자, 비DOM 픽셀은 Computer Use를 사용합니다. 명시적인 $computer-use 요청을 CDP로 대체하지 않습니다.

첫 호출과 동작

노출된 js 도구를 처음 호출할 때 반환되는 문서를 읽고 거기서 설명한 API만 사용합니다. cua.getApp(name), app.getAXState(), app.click(index|[x,y]), app.typeText, app.pressKey 등이 포함됩니다. 요소를 누르기 전에 현재 앱 상태를 읽고 UI가 바뀌면 다시 읽습니다.

// 문서를 읽은 뒤 Computer Use js 도구 안에서
let app = await cua.getApp("Finder");
let state = await app.getAXState();
// 현재 상태의 인덱스를 확인한 뒤 app.click(index)를 호출합니다.

CDP 경로 — cli-jaw browser

Chrome DOM으로 접근 가능한 모든 것에 사용: 페이지 텍스트, 폼 필드, 페이지 내 버튼. 웹 콘텐츠에서 Computer Use보다 10배 빠릅니다.

세션 명령어

cli-jaw browser status                         # 세션이 활성 상태인가?
cli-jaw browser start --agent                  # 헤드리스 자동화 세션
cli-jaw browser start --headless               # 수동 헤드리스 (WSL/CI/Docker)
cli-jaw browser start                          # 가시 창 (사용자 요청 시에만)
cli-jaw browser navigate "https://example.com" # URL로 이동
cli-jaw browser open "https://example.com"     # 새 탭에서 열기
cli-jaw browser tabs                           # 탭 목록

스냅샷 + 액션

cli-jaw browser snapshot --interactive   # 클릭 가능한 요소 목록 (e1, e2, ...)
cli-jaw browser click e3                 # 참조로 클릭
cli-jaw browser type e5 "query" --submit # 입력 + Enter
cli-jaw browser press Enter              # 폴백 키 입력
cli-jaw browser screenshot               # PNG 저장
cli-jaw browser text                     # 화면 텍스트 덤프
참조 ID는 매 navigate 후 초기화됩니다. 새 페이지로 이동한 후에는 반드시 스냅샷을 다시 찍으세요.

CDP 액션 클래스 매핑

명령어액션 클래스계약
snapshot, text, screenshotstate-readTX-00

설정과 실패

Computer Use가 포함된 ChatGPT 데스크톱 앱을 설치하고 연 뒤 jaw를 다시 시작해 jaw-computer-use를 등록합니다. Jaw는 데스크톱 플러그인 캐시에서 최신 번들 cua_repl을 찾습니다. macOS에서는 jaw 서비스를 실행한 프로세스/바이너리에 다른 앱 데이터 접근 권한(TCC App Data, ChatGPT Computer Use 컨테이너)이 필요할 수 있습니다. 개인정보 보호 및 보안에서 부여하며 패널 이름은 macOS 버전에 따라 다릅니다. 권한이 없는 Terminal 실행 jaw는 첫 앱 호출에서 멈출 수 있습니다. Windows에도 데스크톱 플러그인 캐시가 필요합니다. Linux, WSL, Docker에는 호스트 Computer Use 표면이 없습니다.

Jaw는 실행 권한 정책에 따라 앱 승인 요청에 응답합니다. auto는 승인하고 safe는 거절하며 not approved로 보고합니다.

상황보고
Computer Use 도구가 없음precondition failed: no Computer Use surface
첫 앱 호출이 막힘precondition failed: computer-use app access blocked
safe 정책이 앱 승인을 거절not approved

도구가 없으면 Computer Use가 포함된 ChatGPT 데스크톱 앱을 설치하거나 열고 jaw를 다시 시작합니다. Linux, WSL, Docker에서도 일반 DOM 작업에는 CDP를 사용할 수 있습니다.
