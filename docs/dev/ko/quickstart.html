빠른 시작

CLI-JAW를 설치하고 5분 안에 첫 AI 에이전트 세션을 시작하세요.

사전 요구사항

  • Node.js 22.4+ — nodejs.org
  • npm (Node.js에 포함)
  • 최소 하나의 AI CLI 구독 (예: Claude Code는 Claude Pro 이상, Codex는 ChatGPT Pro 이상, Gemini CLI는 Google AI)

설치

macOS / Linux

npm install -g cli-jaw

Windows

Windows는 WSL(Windows Subsystem for Linux)이 필요합니다. 먼저 WSL을 설치한 후, 시작 메뉴에서 Ubuntu를 열고 거기서 명령어를 실행하세요.
# WSL Ubuntu 터미널에서:
npm install -g cli-jaw

Windows 상세 가이드: Windows 설정

초기 설정

jaw init

설정 마법사가 다음을 안내합니다:

  1. 기본 CLI 선택 (Claude Code, Codex, Gemini CLI 등)
  2. CLI 구독 인증
  3. 서버 포트 설정 (기본값: 3457)

CLI 인증

각 CLI는 자체 구독으로 인증합니다. 별도 터미널에서 로그인하세요:

# Claude Code (Claude Pro 구독 이상 필요)
claude

# Codex (ChatGPT Pro 구독 이상 필요)
codex

# Gemini CLI (Google AI 구독 필요)
gemini
기본 프리미엄 모델은 Claude claude-opus-4-8, Codex gpt-5.5입니다. 6월부터 구독제에 포함된 Claude 사용량을 쓰려면 claude를 선택하세요.

그 다음 jaw에서 사용할 CLI를 설정하세요:

jaw init   # 또는 채팅에서 /cli claude
settings.json의 API 키는 음성인식(Gemini API)이나 이미지 생성(OpenAI API) 같은 선택 기능에만 필요합니다. 메인 CLI 인증은 각 도구의 로그인으로 처리됩니다.

설치 확인

jaw doctor

설정을 확인하고 문제가 있으면 보고합니다.

문제 해결

에러해결 방법
command not found: jawnpm 글로벌 bin이 PATH에 있는지 확인. npm bin -g로 경로 확인.
EACCES permission deniedsudo npm install -g cli-jaw를 사용하거나 npm 권한 수정.
node: command not foundnodejs.org에서 Node.js 22.4+ 설치.
