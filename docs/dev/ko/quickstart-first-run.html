첫 실행

단일 인스턴스 모드와 다중 인스턴스 모드 중 하나를 선택한 후, 첫 메시지를 보내보세요.

두 가지 실행 방법

명령어모드적합한 용도
jaw serve단일 인스턴스간단한 일회성 작업, 간편한 설정
jaw dashboard다중 인스턴스 관리여러 에이전트 실행, 전체 대시보드

단일 인스턴스: jaw serve

jaw serve
# Opens browser at http://localhost:3457

즉시 채팅 인터페이스가 열립니다. 메시지를 입력하면 AI 에이전트가 응답합니다.

다중 인스턴스: jaw dashboard

jaw dashboard
# Opens browser at http://localhost:24576

대시보드에서 모든 인스턴스를 확인할 수 있습니다. Start를 클릭하여 인스턴스를 실행하거나, Perm을 클릭하여 재부팅 후에도 유지되도록 설정할 수 있습니다.

첫 메시지 보내기

채팅 입력창에 메시지를 입력하고 Enter를 누르세요. AI 에이전트가 설정된 CLI(기본값은 Claude Code)를 사용하여 응답합니다.

CLI / 모델 전환

/cli claude    # Switch to Claude Code
/cli codex     # Switch to Codex
/cli gemini    # Switch to Gemini CLI
/model claude-opus-4-8  # Change model
Codex에서는 /model gpt-5.5를 사용하세요. 6월부터 구독제에 포함된 Claude 사용량을 쓰려면 /cli claude를 선택하세요.

인스턴스 제어

  • Start — 인스턴스 실행 (대시보드가 열려 있는 동안 동작)
  • Stop — 인스턴스 중지
  • Perm — launchd/systemd를 통해 영구 실행 (재부팅 후에도 유지)
