CLI-JAW 문서

모든 AI 구독을 하나로. CLI-JAW는 Claude, ChatGPT, Codex, Gemini, Grok, Kiro를 통합 멀티에이전트 오케스트레이션 플랫폼으로 연결합니다.

npm install -g cli-jaw jaw dashboard

CLI-JAW란?

CLI-JAW는 여러 AI 코딩 에이전트(Claude Code, Codex, Gemini CLI, Kiro, OpenCode, Copilot CLI)를 하나의 대시보드에서 실행할 수 있는 오픈소스 플랫폼입니다. 메인 에이전트가 다른 CLI 에이전트에게 작업을 위임하는 직원 시스템, 구조화된 개발을 위한 PABCD 오케스트레이션 워크플로우, 영속적인 메모리와 목표, 내장 노트 워크스페이스, 칸반 보드, 그리고 Telegram/Discord 연동을 제공합니다.

주요 기능

기능설명
다중 인스턴스 대시보드7개 이상의 에이전트를 동시 실행. 하나의 UI에서 시작, 정지, 관리.
직원 시스템메인 에이전트가 다른 CLI 도구를 "직원"으로 호출하여 작업 위임.
PABCD 오케스트레이션Plan → Audit → Build → Check → Done. 구조화된 개발 워크플로우.
Jawsidian 노트그래프 뷰, 위키링크, 이미지 붙여넣기를 지원하는 내장 마크다운 에디터.
칸반 보드Backlog → Active → Review → Done 레인으로 작업 관리.
200+ 참조 스킬도메인 지식, 자동화, 오피스, 브라우저, 미디어, 배포 스킬. AI가 필요한 런타임 스킬을 활성화.
Goal 시스템세션 간에도 유지되는 영속적 목표 추적.
Computer UseCodex 직원 연동을 통한 데스크톱 자동화.
Telegram / Discord메시징 앱에서 원격으로 AI 에이전트 제어.
Electron 데스크톱터미널, 디프 뷰어, 폴더 패널, 브라우저 탭을 갖춘 네이티브 앱.

아키텍처 개요

CLI-JAW는 루트 핸들러와 200개의 API/미디어 엔드포인트를 포함하는 Node.js 22 서버로 구성됩니다. CLI, 터미널 TUI, Web PWA, Electron 데스크톱, Telegram, Discord, Manager 대시보드가 서버와 공유 SQLite 상태를 통해 연결됩니다. 전체 시스템 설계는 아키텍처 페이지에서 확인하세요.

CLI/TUI/Electron/Web/Telegram/Discord ──→ server.ts ──→ src/routes/*
Web events                              ──→ GET /api/events (SSE) ──→ event-bus
Dashboard (port 24576)                  ──→ src/manager/ + public/manager/
Agent streams                           ──→ NDJSON provider events + trace files
