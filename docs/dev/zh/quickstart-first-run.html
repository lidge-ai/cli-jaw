首次运行

选择单实例或多实例模式，然后发送你的第一条消息。

两种运行方式

命令模式适用场景
jaw serve单实例快速一次性任务，简单设置
jaw dashboard多实例管理器运行多个代理，完整仪表盘

单实例：jaw serve

jaw serve
# Opens browser at http://localhost:3457

你将立即获得一个聊天界面。输入消息，你的 AI 代理就会回复。

多实例：jaw dashboard

jaw dashboard
# Opens browser at http://localhost:24576

仪表盘会显示你的所有实例。点击 Start 启动一个实例，或点击 Perm 使其在重启后持续运行。

发送你的第一条消息

在聊天输入框中输入内容并按回车。AI 代理将使用你配置的 CLI（默认为 Claude Code）进行回复。

切换 CLI / 模型

/cli claude    # Switch to Claude Code
/cli codex     # Switch to Codex
/cli gemini    # Switch to Gemini CLI
/model claude-opus-4-8  # Change model
在 Codex 中使用 /model gpt-5.5。自 6 月起，如果要使用订阅计划赠送的 Claude 用量，请选择 /cli claude。

实例控制

  • Start — 启动实例（在仪表盘打开期间运行）
  • Stop — 停止实例
  • Perm — 通过 launchd/systemd 持久化（重启后仍然存活）
