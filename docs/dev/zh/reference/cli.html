CLI 命令

CLI-JAW 提供聊天界面的斜杠命令、终端中的 26 个根路由器分支，以及 chat search、browser web-ai、dashboard memory/chat search 等分组 CLI 表面。

根 CLI 子命令

这些命令直接在终端中以 jaw <command> 方式运行：

命令说明
jaw serve启动单实例服务器
jaw dashboard启动多实例仪表盘
jaw init交互式设置向导
jaw doctor诊断安装问题
jaw status服务器健康检查
jaw chat终端 REPL
jaw dispatch分派员工任务
jaw employee员工管理
jaw orchestratePABCD 状态机
jaw goal目标生命周期管理
jaw memory记忆搜索/读取/保存
jaw browserChrome CDP 浏览器控制
jaw skill技能管理
jaw mcpMCP 服务器管理
jaw service系统服务管理
jaw clone克隆实例
jaw connector仪表盘连接器
jaw reminders提醒管理
jaw project项目目录管理
jaw reset重置配置

斜杠命令（聊天界面）

在聊天输入框中以 / 为前缀输入这些命令：

会话

命令参数说明
/help显示帮助
/commands列出所有命令
/status会话状态
/clear清除聊天记录
/compact压缩上下文
/reset[scope]重置会话

工作流

命令参数说明
/plan[task]生成实施计划
/interview[request]澄清需求（1-3 个问题）
/deliberate[topic]深度推理
/planaudit[plan]审计计划
/goal<sub>目标管理（set/done/cancel/...）
/team<sub>并行团队编排

模型

命令参数说明
/model[name]切换 AI 模型
/cli[name]切换 CLI 运行时
/fallback[provider]设置回退提供商
/forward[provider]转发至提供商
/thought[toggle]切换扩展思考
/flush刷新待处理输出

工具

命令参数说明
/skill[sub]技能管理
/employee[sub]员工管理
/mcp[sub]MCP 服务器管理
/memory[query]记忆搜索
/browser[sub]浏览器控制
/orchestrate[phase]PABCD 编排
/project[sub]项目设置
