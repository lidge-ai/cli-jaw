Productivity Skills

文档创建、知识管理、任务跟踪、笔记和韩语内容写作技能。这 17 项技能将 CLI-JAW 连接到办公套件、项目管理工具、个人生产力应用和编辑工作流，让您可以完全通过聊天界面创建、阅读、编辑和组织文档、任务与内容。

概述

生产力技能分为五组：文档格式（Office 和 HWP 文件读写）、知识管理（Notion、Obsidian、Apple Notes）、任务管理（Things、Reminders、Trello、Linear）、协作工具（协同编辑、HTML 转 PPTX 转换）以及内容写作（通过 k-writing 生成韩语推广/编辑内容）。

技能状态类别描述
docx已激活文档创建、阅读和编辑 Word (.docx) 文件
pptx已激活文档创建、阅读和编辑 PowerPoint (.pptx) 演示文稿
xlsx已激活文档创建、阅读和编辑 Excel (.xlsx) 电子表格
hwp已激活文档创建、阅读和编辑韩文 HWP/HWPX 文档
k-writing已激活内容韩语推广/内容写作，包含渠道路由、强制预搜索、3 候选钩子评分以及去 AI 痕迹/拟人化校验
notion已激活知识阅读、创建和更新 Notion 页面和数据库
notion-knowledge-capture计划中知识自动将对话洞察捕获到 Notion
notion-meeting计划中知识含待办事项的会议记录模板，同步到 Notion
notion-research计划中知识将研究发现汇总到 Notion 数据库
notion-spec计划中知识集成 Notion 的产品规格起草
apple-notes计划中知识通过 AppleScript 创建和搜索 Apple Notes
obsidian计划中知识读取和写入 Obsidian 知识库的 Markdown 文件
apple-reminders计划中任务通过 AppleScript 创建和管理 Apple Reminders
things-mac计划中任务在 Mac 版 Things 3 中创建和管理任务
trello计划中任务创建卡片、在列表间移动、管理 Trello 看板
linear计划中任务创建问题、更新状态、查询 Linear 项目
doc-coauthoring计划中协作AI 辅助的实时协作文档编辑
html2pptx计划中协作将 HTML 内容转换为 PowerPoint 幻灯片

文档技能

四项文档技能（docx、pptx、xlsx、hwp）目前均已激活，并为各自的格式提供完整的读取/写入/编辑功能。

docx -- Word Documents

使用结构化内容块创建和编辑 .docx 文件。支持标题、段落、表格、项目符号列表、图片和自定义样式。

# Create a new Word document
"프로젝트 보고서를 docx로 만들어줘"

# Read and summarize an existing document
"이 docx 파일 읽어서 요약해줘"

# Edit specific sections
"3번째 섹션의 표를 업데이트해줘"

pptx -- PowerPoint Presentations

生成包含布局、文本框、图片、图表和演讲者备注的幻灯片。支持母版幻灯片模板和自定义主题。

# Create a presentation from scratch
"PPT 만들어줘 -- 10장짜리 프로젝트 발표용"

# Add slides to existing presentation
"이 PPT에 요약 슬라이드 추가해줘"

# Convert content to slides
"이 마크다운을 PPT로 변환해줘"

xlsx -- Excel Spreadsheets

创建和操作包含公式、图表、条件格式、数据透视表和多工作表的电子表格。

# Create a budget spreadsheet
"월별 예산 엑셀 만들어줘"

# Analyze existing data
"이 엑셀 데이터 분석해서 차트 추가해줘"

# Generate report from data
"매출 데이터로 분기별 보고서 엑셀 만들어줘"

hwp -- Korean HWP/HWPX Documents

全面支持 Hancom Office 的 HWP 和 HWPX (OWPML) 格式。处理韩文特有的文档布局、表格和格式。可通过关键词如 한글、.hwp、.hwpx、한컴오피스 或 OWPML 触发。

# Read an HWP file
"한글 문서 읽어줘"

# Create an official Korean document
"공문서 양식으로 한글 파일 만들어줘"

# Convert between formats
"이 hwp 파일을 docx로 변환해줘"
提示： 所有文档技能会自动检测您提示语的语言。韩文提示如 "PPT 만들어줘" 或 "한글 문서 읽어줘" 可以与英文命令自然混用。技能会自动处理编码、字体和地区特定的格式。

知识管理

这些技能与笔记和知识库平台集成，用于捕获、组织和检索信息。

notion

核心 Notion 集成技能，目前已激活。连接 Notion API 以读取页面、创建新页面、更新内容和查询数据库。

# Create a page in Notion
"노션에 정리해줘 -- 오늘 회의 내용"

# Query a database
"노션 프로젝트 DB에서 진행중인 태스크 보여줘"

# Update an existing page
"노션 위클리 리포트 페이지 업데이트해줘"
子技能状态用途
notion-knowledge-capture计划中自动将对话中的关键洞察、决策和经验捕获到结构化的 Notion 数据库中
notion-meeting计划中生成包含参会人、议程、讨论要点和待办事项的会议记录页面
notion-research计划中将网络搜索和深度研究的研究发现汇总到 Notion 中，并附带引用
notion-spec计划中起草包含需求、用户故事和验收标准的产品规格

apple-notes（计划中）

通过 AppleScript 在 macOS 上与 Apple Notes 集成。将支持跨文件夹创建、搜索、阅读和追加笔记。

# Create a quick note
"애플 노트에 메모 남겨줘: 내일 미팅 준비사항"

# Search notes
"애플 노트에서 지난주 메모 검색해줘"

obsidian（计划中）

与 Obsidian 知识库的直接集成。将支持读写 Markdown 文件、管理标签、创建维基链接，并遵循知识库的文件夹结构。

# Create a note in Obsidian
"옵시디언에 새 노트 만들어줘: 아키텍처 결정 기록"

# Search vault
"옵시디언 볼트에서 API 관련 노트 찾아줘"

任务管理

任务管理技能将 CLI-JAW 连接到流行的待办事项和项目跟踪工具。目前均为计划中。

apple-reminders（计划中）

通过 AppleScript 在 Apple Reminders 中创建和管理提醒。支持截止日期、优先级、列表和循环提醒。

# Add a reminder
"리마인더에 추가해줘: 금요일까지 보고서 제출"

# List today's reminders
"오늘 리마인더 보여줘"

things-mac（计划中）

通过 URL scheme 和 AppleScript 与 Mac 版 Things 3 集成。将支持创建待办事项、项目、区域和管理标签。

# Create a to-do
"Things에 할일 추가해줘: 코드 리뷰"

# Create a project with tasks
"Things에 새 프로젝트 만들어줘 -- 릴리즈 체크리스트"

trello（计划中）

通过 Trello REST API 管理 Trello 看板、列表和卡片。将支持创建卡片、在列表间移动、添加标签、清单和附件。

# Create a card
"트렐로 보드에 카드 추가해줘: 버그 수정 필요"

# Move a card
"트렐로에서 이 카드를 Done으로 옮겨줘"

linear（计划中）

与 Linear 项目管理集成。将支持通过 Linear GraphQL API 创建问题、更新状态、查询项目和管理周期。

# Create an issue
"리니어에 이슈 만들어줘: 로그인 페이지 리디자인"

# Query project status
"리니어에서 이번 사이클 진행 상황 보여줘"

协作工具

用于文档协作和格式转换工作流的专用技能。

doc-coauthoring（计划中）

启用实时协作文档编辑，AI 协助起草、审阅和完善文档，与人工输入并行工作。将支持版本跟踪、建议模式和评论解决。

# Start co-authoring session
"이 보고서 같이 작성하자 -- 내가 개요 쓸 테니 본문 채워줘"

# Review and suggest edits
"이 문서 리뷰하고 수정 제안해줘"

html2pptx（计划中）

将 HTML 内容（网页、渲染后的 Markdown、报告输出）转换为格式化的 PowerPoint 幻灯片。适用于将研究结果或仪表板导出内容转换为可演示的幻灯片。

# Convert HTML report to slides
"이 HTML 리포트를 PPT로 변환해줘"

# Web page to presentation
"이 웹페이지 내용을 발표자료로 만들어줘"
自然语言触发： 您无需记住技能名称。只需用自然语言描述您的需求即可。示例：
  • "PPT 만들어줘" 触发 pptx 技能
  • "노션에 정리해줘" 触发 notion 技能
  • "한글 문서 읽어줘" 触发 hwp 技能
  • "엑셀로 정리해줘" 触发 xlsx 技能
  • "이거 홍보 쓰레드로 써줘" 触发活跃的 k-writing 技能
  • "리마인더에 추가해줘" 将触发 apple-reminders
  • "트렐로에 카드 만들어줘" 将触发 trello
CLI-JAW 会自动将您的意图匹配到相应的技能。

配置

部分生产力技能需要 API 令牌或特定于应用的设置。请在 CLI-JAW 设置或环境变量中进行配置。

技能要求配置
notionNotion API 令牌在环境变量或 settings.json 中设置 NOTION_API_KEY
trelloTrello API 密钥 + 令牌TRELLO_API_KEY、TRELLO_TOKEN
linearLinear API 密钥LINEAR_API_KEY
obsidian知识库路径在设置中配置 OBSIDIAN_VAULT_PATH
docx / pptx / xlsx无开箱即用
hwp无开箱即用
apple-notes / apple-reminders / things-macmacOS需在系统设置中允许 AppleScript 访问

技能交互

生产力技能可以与 CLI-JAW 的其他功能自然组合：

  • deep-research + notion：研究某个主题并将发现保存到 Notion 数据库
  • xlsx + pptx：分析电子表格数据并生成带图表的演示文稿
  • hwp + docx：在韩文 HWP 和 Word 格式之间转换
  • k-writing + search：结合最新来源检查、钩子评分和去 AI 痕迹审查来生成韩语推广文案
  • notion-meeting + telegram：捕获会议记录并通过 Telegram 发送摘要
  • html2pptx + web-ai：抓取网页并将其转换为幻灯片
  • linear + trello：跨项目管理工具同步问题状态
