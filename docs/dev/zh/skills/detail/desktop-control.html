Desktop Control 启用

桌面应用和浏览器窗口控件使用 Computer Use 工具；普通网页 DOM 使用 jaw browser。

技能 ID：desktop-control
工具：jaw-computer-use MCP 服务器的 js；Codex 使用原生 Computer Use 插件
主机：macOS，或具备 Codex 桌面插件缓存的 Windows

选择执行路径

Computer Use 是 MCP 工具，不是员工。Jaw 为除 Codex 以外支持 MCP 的 CLI 注册 jaw-computer-use；在 Claude 中显示为 mcp__jaw-computer-use__js。Codex 主代理和员工使用 Codex 原生 Computer Use 插件。较长的图形界面任务可委派给拥有相同工具的任何员工，无须专用 Control 员工。

网页 DOM 使用 jaw browser snapshot --interactive 返回的引用。桌面应用窗口、浏览器窗口控件、系统对话框和非 DOM 像素使用 Computer Use。明确指定 $computer-use 时，不得暗中改用 CDP。

首次调用与操作

首次调用暴露的 js 工具时，先阅读其返回的文档，只使用文档描述的 API，包括 cua.getApp(name)、app.getAXState()、app.click(index|[x,y])、app.typeText 和 app.pressKey。操作元素前读取当前应用状态，界面变化后重新读取。

// 阅读文档后，在 Computer Use js 工具中执行
let app = await cua.getApp("Finder");
let state = await app.getAXState();
// 从当前状态确认索引后再调用 app.click(index)。

CDP 路径 — cli-jaw browser

适用于所有可通过 Chrome DOM 定位的内容：页面文本、表单字段、页面内的按钮。处理 Web 内容时比 Computer Use 快 10 倍。

会话命令

cli-jaw browser status                         # 会话是否活跃？
cli-jaw browser start --agent                  # 无头自动化会话
cli-jaw browser start --headless               # 手动无头模式（WSL/CI/Docker）
cli-jaw browser start                          # 可见窗口（仅在用户要求时使用）
cli-jaw browser navigate "https://example.com" # 导航到 URL
cli-jaw browser open "https://example.com"     # 在新标签页中打开
cli-jaw browser tabs                           # 列出标签页

快照 + 操作

cli-jaw browser snapshot --interactive   # 列出可点击元素（e1、e2、...）
cli-jaw browser click e3                 # 通过引用点击
cli-jaw browser type e5 "query" --submit # 输入 + 回车
cli-jaw browser press Enter              # 备用按键
cli-jaw browser screenshot               # 保存 PNG 截图
cli-jaw browser text                     # 输出可见文本
导航后引用 ID 会重置。 导航到新页面后务必重新获取快照。

设置与故障

安装并打开带有 Computer Use 的 ChatGPT 桌面应用，然后重启 jaw 以注册 jaw-computer-use。Jaw 从桌面插件缓存中查找最新的捆绑 cua_repl。在 macOS 上，启动 jaw 服务的进程或二进制文件可能需要访问其他应用数据的权限（ChatGPT Computer Use 容器的 TCC App Data）。在“隐私与安全性”中授予；具体面板名称因 macOS 版本而异。未获授权的 Terminal 启动实例可能在首次应用调用时阻塞。Windows 同样需要桌面插件缓存。Linux、WSL 和 Docker 没有主机 Computer Use 接口。

Jaw 按本次运行的权限策略处理应用批准提示：auto 批准，safe 拒绝并报告 not approved。

情况报告
没有 Computer Use 工具precondition failed: no Computer Use surface
首次应用调用被阻塞precondition failed: computer-use app access blocked
safe 策略拒绝批准not approved

若工具缺失，安装或打开带有 Computer Use 的 ChatGPT 桌面应用并重启 jaw。Linux、WSL 和 Docker 仍可用 CDP 处理普通 DOM 工作。
