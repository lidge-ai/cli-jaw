快速开始

安装 CLI-JAW 并在 5 分钟内启动您的第一个 AI 代理会话。

前提条件

  • Node.js 22.4+ — nodejs.org
  • npm（随 Node.js 一起安装）
  • 至少订阅一个 AI CLI（例如：Claude Code 需要 Claude Pro 或更高订阅，Codex 需要 ChatGPT Pro 或更高订阅，Gemini CLI 需要 Google AI）
默认高级模型为 Claude claude-opus-4-8 和 Codex gpt-5.5。自 6 月起，如果要使用订阅计划赠送的 Claude 用量，请选择 claude。

安装

macOS / Linux

npm install -g cli-jaw

Windows

Windows 需要 WSL（适用于 Linux 的 Windows 子系统）。请先安装 WSL，然后从开始菜单打开 Ubuntu 并在其中运行命令。
# In WSL Ubuntu terminal:
npm install -g cli-jaw

详细的 Windows 指南：Windows Setup

初始设置

jaw init

设置向导将引导您完成以下步骤：

  1. 选择您的主要 CLI（Claude Code、Codex、Gemini CLI 等）
  2. 认证您的 CLI 订阅
  3. 配置服务器端口（默认：3457）

CLI 认证

每个 CLI 都通过自己的订阅登录。在单独的终端中运行对应的登录命令：

# Claude Code（需要 Claude Pro 或更高订阅）
claude

# Codex（需要 ChatGPT Pro 或更高订阅）
codex

# Gemini CLI（需要 Google AI 订阅）
gemini
settings.json 中的 API 密钥只用于语音识别（Gemini API）或图像生成（OpenAI API）等可选功能。主要 CLI 认证由每个工具自己的登录流程处理。

验证安装

jaw doctor

此命令会检查您的设置并报告任何问题。

故障排除

错误解决方法
command not found: jaw确保 npm 全局 bin 目录在您的 PATH 中。运行 npm bin -g 查看路径。
EACCES permission denied使用 sudo npm install -g cli-jaw 或修复 npm 权限。
node: command not found从 nodejs.org 安装 Node.js 22.4+
