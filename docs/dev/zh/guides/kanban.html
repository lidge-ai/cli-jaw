看板

内置看板提供标准工作流泳道的任务管理功能。可通过仪表盘的 Board 选项卡访问。

工作流泳道

任务按以下泳道流转：

泳道用途
Backlog等待开始的任务
Ready已准备就绪可以开始的任务
Active正在进行中的任务
Review已完成并等待审核的任务
Done已完成的任务

卡片操作

  • 创建 -- 在任意泳道中添加新卡片
  • 编辑 -- 更新卡片标题、描述和元数据
  • 移动 -- 在泳道之间拖拽卡片或在泳道内重新排序
  • 删除 -- 从看板中移除卡片

看板 API

方法路径描述
GET/api/dashboard/board/tasks列出所有任务
POST/api/dashboard/board/tasks创建任务
PATCH/api/dashboard/board/tasks更新任务（移动、编辑）
DELETE/api/dashboard/board/tasks删除任务

CLI 访问

# Add a task
jaw connector board add "Implement user auth" --lane backlog

# Update a task
jaw connector board update <id> --lane active

# List tasks
jaw connector board list
