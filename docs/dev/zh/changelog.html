CLI-JAW 2.0.0 正式版以来的发布历史。

未发布 — 2026-06-28

修复

  • Manager UI 边界 — Worker progress monitor 不再渲染在按实例的 Jaw 侧边栏内；Code/CEO 运行时观测仅保留在专用 Code lane。
  • Watchdog 诊断 — 回合停滞时，idle/progress watchdog 终止原因会显示在 Telegram 中。

v2.2.3 — 2026-06-27

发布

  • 稳定版 npm latest 发布，含 GitHub OIDC Trusted Publishing 与桌面资源流水线。
  • 包含 v2.2.2 线的 Telegram Hub P4 加固、AGY capability-probe 门控、goal pause gate 文档对齐与 release-gate CI 调整。

v2.2.2 — 2026-06-25

修复

  • Dashboard Notes：裸 .md 文件名不再自动超链接到 Jawsidian 路由。
  • Adaptive-fetch 截止时间取消扩展至 browser/CDP 阶段。

新功能

  • /skill:<id> 斜杠命令在 CLI/Web 暴露活跃运行时技能。
  • 开发者文档 skills 目录从 live registry 重建。

v2.2.1 — 2026-06-23

新功能

  • 外部 JWC 运行时助手（jaw jwc install|doctor|clean）— 可选，不捆绑在 npm/Electron 中。
  • Adaptive URL fetch（jaw browser fetch）P0 缺口关闭：SSRF 防护、warm browser pool、BM25 过滤、Camoufox stealth、yt-dlp reader。
  • 从 skills_ref/ 默认激活技能（search、goal、structured-renderers 等）。
  • Worker progress monitor API 与 manager runtime-status 桥接。

v2.2.0 — 2026-06-22

新功能

  • 统一 release 分支策略与强化的 release-gate CI 契约。
  • 在测试中标注 strict TypeScript interop 边界。

v2.1.5 — 2026-06-15

桌面

  • 在 macOS/Windows/Linux CI 矩阵中验证 Electron 桌面壳。
  • 记录未签名桌面资源分发；npm 包仍为 CLI 专用。

v2.1.3 — 2026-06-04

  • Goal heartbeat、workflow scope 控制与 manager 打磨。
  • Electron 原生文件拖放路由到活跃工作区。

  • 聊天内联媒体渲染（图片/视频、lightbox、/media/:filename 路由）。
  • Goal continuation 以审计完成流覆盖 PABCD 阶段门控。

v2.1.0 — 2026-05-29

从 2.0.x 线过渡到 2.1 运行时扩展（Kiro/AGY/Pi parity 在后续补丁中继续）。

v2.0.17 — 2026-05-29

新功能

  • IDE 键盘快捷键：Cmd+W 关闭标签页，Cmd+1-4 切换标签页，Cmd+Shift+[/] 标签页导航
  • 浏览器面板快捷键：Cmd+L（URL 栏），Cmd+R（刷新），Cmd+Shift+R（强制刷新），Cmd+Left/Right（前进/后退）
  • 终端快捷键：Cmd+K（清屏），Cmd+T（新建标签页）
  • Cmd+Shift+B 切换左侧边栏（实例列表）
  • 移除右侧面板宽度上限 -- 可自由扩展
  • cli-jaw goal CLI 子命令（set/status/done/cancel/update/history）
  • 目标续行功能现在在 PABCD 阶段中触发

修复

  • Electron 权限策略：默认允许，使用安全拒绝列表
  • 移除预览权限提示（不再出现 "background-sync blocked" 提示）
  • 前端 tsc 类型安全：PanelBusAction 联合类型
  • 焦点范围快捷键（浏览器/终端操作仅在获得焦点时触发）
  • PanelLayoutProvider 过期闭包修复
  • Cmd+K 冲突解决（保留 CommandPalette，移除菜单加速器）
