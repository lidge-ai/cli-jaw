Tool Commands

工具命令用于管理 CLI-JAW 的内部子系统 — 技能、员工、MCP 服务器、记忆、浏览器、编排和项目目录。这些斜杠命令可在任何 CLI-JAW 会话中使用。

所有工具命令都以 / 开头，也可以通过自然语言触发。韩语 "~해줘" 模式会自动映射 — 请参阅每个命令下方的提示框。

命令概览

命令用途韩语快捷方式
/skill技能管理（列表、重置）"스킬 목록 보여줘"
/employee员工重置"직원 리셋해줘"
/mcpMCP 服务器管理"MCP 서버 동기화해줘"
/memory记忆搜索"메모리 검색해줘"
/browser浏览器控制"브라우저 상태 보여줘"

/skill

管理技能目录。列出所有可用技能及其激活状态，或将技能系统重置为默认值。

子命令

子命令参数描述
/skill list—显示所有已注册的技能及其状态（活跃、已加载、可用）。自动激活的技能会带有标记。
/skill reset—将所有技能重置为默认状态。卸载手动加载的技能并恢复自动激活的技能。

使用示例

# List all skills and their activation status
/skill list

# Reset skills after experimenting with manual loads
/skill reset
"~해줘" 提示： "스킬 목록 보여줘" → /skill list  |  "스킬 초기화해줘" → /skill reset

/employee

重置员工系统。员工是处理委派任务的专用子代理。当员工卡住或其状态过时时，可以重置它。

子命令

子命令参数描述
/employee reset—将所有员工重置为初始状态。清除排队的任务，重置内部计数器，并重新初始化员工池。

使用示例

# Reset all employees when tasks are stuck
/employee reset

# Useful after changing project context
/employee reset
"~해줘" 提示： "직원 리셋해줘" → /employee reset  |  "employee 초기화" → /employee reset

/mcp

管理 MCP（模型上下文协议）服务器。MCP 服务器通过提供额外的工具、资源和上下文来扩展 CLI-JAW 的功能。同步操作会发现可用的服务器；安装操作会添加新的服务器。

子命令

子命令参数描述
/mcp sync—与所有已配置的 MCP 服务器同步。重新发现可用工具，刷新服务器健康状态，并更新工具注册表。
/mcp install—从已配置的服务器列表中安装或注册新的 MCP 服务器。获取服务器清单并注册其工具。

使用示例

# Refresh all MCP server connections
/mcp sync

# Install a new MCP server after adding it to config
/mcp install

# Typical workflow: add server to config, then install + sync
/mcp install
/mcp sync
"~해줘" 提示： "MCP 서버 동기화해줘" → /mcp sync  |  "MCP 설치해줘" → /mcp install

/memory

搜索 CLI-JAW 的持久化记忆系统。记忆系统跨会话存储决策、上下文和事实信息。使用此命令可以回忆之前的上下文或验证系统记住了什么。

语法

形式参数描述
/memory—不带查询词打开记忆搜索（列出最近的条目）。
/memory [query]query — 自由文本搜索字符串在记忆中搜索与查询匹配的条目。使用语义搜索覆盖所有记忆层（L0 会话、L1 项目、L2 联邦）。

使用示例

# Search for JWT-related decisions
/memory JWT authentication

# Find previous architecture discussions
/memory architecture decisions

# Broad search across all memory
/memory deployment strategy

# No query — see recent memory entries
/memory

记忆层级

层级范围描述
L0会话当前对话上下文，临时性
L1项目以 SQLite 存储的每项目持久化记忆
L2联邦通过仪表盘记忆联邦进行的跨实例搜索
"~해줘" 提示： "메모리 검색해줘" → /memory  |  "JWT 관련 기억 찾아줘" → /memory JWT  |  "이전에 뭐라고 했는지 찾아줘" → /memory [키워드]

/browser

控制由 CLI-JAW 管理的无头 Chrome 浏览器实例。检查浏览器健康状态，列出已打开的标签页，并管理用于网页自动化和截图的浏览器会话。

子命令

子命令参数描述
/browser status—显示当前浏览器状态：CLI-JAW 浏览器服务器是否正在运行、Chrome DevTools Protocol (CDP) 连接状态、视口大小和当前页面 URL。
/browser tabs—列出所有已打开的浏览器标签页及其标题、URL 和活跃/非活跃状态。适用于调试多标签页自动化工作流。

使用示例

# Check if the browser is connected and healthy
/browser status

# See all open tabs in the managed browser
/browser tabs

# Typical workflow: check status, then use browser skill
/browser status
"이 페이지 스크린샷 찍어줘"
"~해줘" 提示： "브라우저 상태 보여줘" → /browser status  |  "열린 탭 보여줘" → /browser tabs

/orchestrate

运行 PABCD 编排框架。PABCD 将复杂任务结构化为五个阶段：Intake（接收）、Persona（角色）、Audience（受众）、Behavior（行为）、Context（上下文）、Deliverable（交付物）。使用此命令可以启动结构化工作流、推进各阶段或检查进度。

子命令

子命令参数描述
/orchestrate I—Intake（接收） — 开始编排流程。收集原始任务描述，并在结构化之前澄清需求。
/orchestrate P—Persona（角色） — 定义谁来执行任务（例如"高级后端工程师"、"用户体验研究员"）。设定语气和专业水平。
/orchestrate A—Audience（受众） — 定义谁消费输出（例如"初级开发者"、"产品经理"、"CI 流水线"）。
/orchestrate B—Behavior（行为） — 指定要执行的操作（例如"编写"、"审查"、"重构"、"分析"、"迁移"）。
/orchestrate C—Context（上下文） — 提供背景约束（例如"TypeScript 单体仓库，Node 20，Cloudflare Workers"）。
/orchestrate D—Deliverable（交付物） — 定义预期输出格式（例如"可合并的代码及测试"、"架构图"、"迁移计划"）。
/orchestrate status—显示当前编排进度。展示哪些 PABCD 阶段已完成、待处理或进行中。
/orchestrate reset—重置编排状态。清除所有 PABCD 阶段并返回初始状态。

使用示例

# Start a full PABCD orchestration from intake
/orchestrate I

# Jump directly to defining the Persona phase
/orchestrate P

# Run through the full workflow step by step
/orchestrate I    # Intake: describe the task
/orchestrate P    # Persona: who does it
/orchestrate A    # Audience: who reads it
/orchestrate B    # Behavior: what actions
/orchestrate C    # Context: constraints
/orchestrate D    # Deliverable: output format

# Check progress mid-workflow
/orchestrate status

# Start over if the framing is wrong
/orchestrate reset

PABCD 阶段流程

阶段回答的问题示例
I — Intake原始任务是什么？"构建一个使用 JWT 的用户认证系统"
P — Persona谁来执行？具有安全专长的高级后端工程师
A — Audience谁消费输出？加入团队的初级开发者
B — Behavior采取什么行动？设计、实现、编写测试、编写文档
C — Context有哪些约束？Express + TypeScript，PostgreSQL，部署在 Cloudflare 上
D — Deliverable输出格式是什么？可合并的代码，包含单元测试和 API 文档
"~해줘" 提示： "PABCD 시작해줘" → /orchestrate I  |  "오케스트레이션 상태 보여줘" → /orchestrate status  |  "PABCD 리셋해줘" → /orchestrate reset

/project

管理项目目录。CLI-JAW 跟踪哪些目录已注册为项目，并将此上下文用于记忆范围划定、技能选择和文件操作。可以在项目之间切换或注册新项目。

子命令

子命令参数描述
/project set[path] — 可选的目录路径设置活跃项目目录。如果未指定路径，则使用当前工作目录。这将更新记忆范围、技能上下文和文件解析。
/project reset—清除活跃项目。重置为无项目上下文，这意味着记忆回退到全局范围，技能失去项目特定的提示。
/project list—列出所有已注册的项目目录及其名称、路径和最后活跃时间戳。

使用示例

# Set the current directory as the active project
/project set

# Set a specific project path
/project set ~/Developer/my-app

# List all known projects
/project list

# Clear the project context
/project reset

# Typical workflow: switch project before starting work
/project set ~/Developer/cli-jaw
"이 프로젝트의 TODO 보여줘"

设置项目后的变化

系统影响
记忆L1 项目记忆的范围限定为所设置的目录
技能针对新项目重新运行技术栈检测（例如检测 TypeScript、Python）
文件相对路径基于项目根目录解析
目标目标跟踪的范围限定为活跃项目
"~해줘" 提示： "프로젝트 설정해줘" → /project set  |  "프로젝트 목록 보여줘" → /project list  |  "프로젝트 초기화해줘" → /project reset
