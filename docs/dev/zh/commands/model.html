Model & CLI Commands

用于切换 AI 模型、切换 CLI 提供商、配置回退链、跨提供商转发请求、切换 Gemini 思考模式以及刷新模型分配的命令。这些命令允许您在会话中动态重新配置 AI 后端，无需重启。

本页上的所有命令均可通过聊天输入框中的斜杠命令调用，也可以使用韩语或英语的自然语言调用。CLI-JAW 能理解类似"클로드로 바꿔줘"的短语，并自动将其映射到相应的命令。

命令摘要

命令参数说明
/model[name]切换当前活跃的 AI 模型
/cli[name]切换当前活跃的 CLI 提供商
/fallback[cli1 cli2 ...|off]设置或禁用回退顺序
/forward[on|off]启用或禁用向其他提供商转发请求
/thought[on|off]切换 Gemini 思考（扩展推理）模式
/flush[cli] [model] | off将模型固定到某个 CLI，或清除固定

/model [name]

在当前 CLI 提供商内切换活跃的 AI 模型。模型名称必须是当前活跃提供商所识别的有效标识符。不带参数调用时，显示当前活跃的模型。

参数

参数是否必需说明
name否要切换到的模型标识符。省略则显示当前模型。

支持的模型（示例）

提供商模型标识符
Claudeclaude-opus-5, claude-opus-5[1m], claude-opus-4-8, claude-opus-4-8[1m], claude-sonnet-4-6, claude-haiku-4-5
Geminigemini-3-flash-preview, gemini-2.5-flash, gemini-2.0-flash
OpenAIgpt-5.5, gpt-5.4, gpt-5.4-mini, gpt-5.3-codex
Grokgrok-3, grok-3-mini
订阅说明：GPT 5.5 和 Claude Opus 4.8 需要 Pro 或更高订阅。自 6 月起，如果要使用订阅计划赠送的 Claude 用量，请选择 claude。

使用示例

# Show current model
/model

# Switch to Claude Opus 4.8
/model claude-opus-4-8

# Switch to Sonnet for lighter tasks
/model claude-sonnet-4-6

# Switch to Gemini 2.5 Pro
/model gemini-3-flash-preview
"~해줘" 提示：说"오퍼스로 바꿔줘"或"소넷으로 전환해줘"，CLI-JAW 会将其映射到正确的 /model 调用。您也可以说"더 똑똑한 모델로 바꿔줘"，编排器会选择最强的可用模型。

/cli [name]

切换活跃的 CLI 提供商。这将更改整个后端 — API 端点、身份验证、可用模型和工具能力都会随提供商的切换而改变。不带参数调用时，显示当前 CLI。

参数

参数是否必需说明
name否要切换到的 CLI 提供商。省略则显示当前 CLI。

支持的 CLI

CLI 名称提供商默认模型
claudeAnthropic Claude Codeclaude-opus-4-8
codexOpenAI Codex CLIgpt-5.5
codex-appOpenAI Codex app servergpt-5.5
geminiGoogle Gemini CLIgemini-3-flash-preview
grokxAI Grokgrok-3
opencodeOpenCode（多提供商）视情况而定
copilotGitHub Copilot视情况而定

使用示例

# Show current CLI
/cli

# Switch to Claude
/cli claude

# Switch to Gemini
/cli gemini

# Switch to Codex
/cli codex

# Switch to Grok
/cli grok
"~해줘" 提示：说"클로드로 바꿔줘"切换到 Claude，"제미나이로 전환해줘"切换到 Gemini，或"코덱스 써줘"切换到 Codex。您也可以说"다른 AI로 바꿔줘"，编排器会询问您偏好哪个提供商。

切换时会发生什么

当您切换 CLI 时，CLI-JAW 会：

  • 优雅地断开与当前提供商的连接
  • 使用默认模型初始化新提供商（除非存在 /flush 固定配置）
  • 在支持的情况下传递对话上下文
  • 更新状态栏和仪表板以反映新的提供商

/fallback [cli1 cli2 ...|off]

配置 CLI 提供商的回退链。如果主 CLI 失败（速率限制、网络错误、API 故障），CLI-JAW 会自动尝试链中的下一个提供商。这确保了即使单个提供商宕机，也能保持不间断的服务。

参数

参数是否必需说明
cli1 cli2 ...否按优先级排列的 CLI 名称列表，以空格分隔
off否完全禁用回退链

使用示例

# Set fallback: try Gemini first, then Codex, then Grok
/fallback gemini codex grok

# Set Claude as the only fallback
/fallback claude

# Disable fallback (only use the active CLI)
/fallback off

# Show current fallback chain
/fallback

回退的工作原理

  1. 请求被发送到活跃的 CLI
  2. 如果活跃 CLI 返回错误（速率限制、超时、5xx），请求会在第一个回退 CLI 上重试
  3. 如果该 CLI 也失败，则移至链中的下一个 CLI
  4. 如果所有回退都已耗尽，错误将呈现给用户
"~해줘" 提示：说"폴백 설정해줘 제미나이 코덱스"来设置回退链，或"폴백 꺼줘"来禁用它。您也可以说"클로드 안 되면 제미나이 써줘"，编排器会自动为您配置回退链。

/forward [on|off]

启用或禁用向其他提供商转发请求。当转发开启时，某些请求可以路由到辅助提供商进行专门处理 — 例如，在使用 Gemini 作为主要对话提供商的同时，将代码生成请求发送到 Claude，或者将图像分析路由到具有视觉能力的模型。

参数

参数是否必需说明
on否启用转发
off否禁用转发

使用示例

# Enable forwarding
/forward on

# Disable forwarding
/forward off

# Show current forwarding status
/forward

何时使用转发

场景主 CLI转发至
聊天时进行代码生成geminiclaude
从纯文本 CLI 执行视觉任务codexgemini
成本优化（轻量任务在本地，重量任务转发）grokclaude
"~해줘" 提示：说"포워딩 켜줘"启用，"포워딩 꺼줘"禁用。您也可以说"코드는 클로드한테 보내줘"，编排器会为您启用转发并设置正确的目标。

/thought [on|off]

切换 Gemini 的思考（扩展推理）模式。启用后，Gemini 会在回复之前使用额外的计算资源逐步推理，类似于 Claude 的扩展思考。这对于复杂任务非常有用，如多步数学题、逻辑谜题或架构决策。仅在 Gemini 为活跃 CLI 时生效。

参数

参数是否必需说明
on否启用思考模式
off否禁用思考模式

使用示例

# Enable Gemini thinking
/thought on

# Disable thinking (faster responses, lower cost)
/thought off

# Show current thinking status
/thought

何时使用思考模式

  • 启用：复杂推理、多步问题、架构决策、调试复杂问题、数学/逻辑
  • 禁用：简单问题、快速编辑、文件操作、常规任务（节省时间和 token）
"~해줘" 提示：说"생각 모드 켜줘"或"thinking 켜줘"启用。说"생각 모드 꺼줘"或"빠르게 답해줘"禁用。仅在 Gemini 为活跃 CLI 时有效 — 对于其他提供商，此命令将被静默忽略。

/flush [cli] [model] | off

将特定模型固定到某个 CLI 提供商，或清除现有的固定。当设置了 flush 固定后，切换到该 CLI 时会自动加载固定的模型，而不是提供商的默认模型。使用 off 来清除所有固定或特定的固定。

参数

参数是否必需说明
cli否要固定模型的 CLI 提供商
model否要固定到该 CLI 的模型
off否清除所有 flush 固定，或在前面加上 CLI 名称时清除特定 CLI 的固定

使用示例

# Pin Claude to always use Opus 4.8
/flush claude claude-opus-4-8

# Pin Gemini to always use 2.5 Pro
/flush gemini gemini-3-flash-preview

# Clear the Claude pin (reverts to default model on next switch)
/flush claude off

# Clear all pins
/flush off

# Show current flush pins
/flush

Flush 固定的工作原理

Flush 固定存储在会话中，在显式清除或会话结束之前持续有效。它们会覆盖提供商的默认模型选择：

  1. 您设置了 /flush claude claude-opus-4-8
  2. 之后，您使用 /cli gemini 切换到 Gemini
  3. 当您使用 /cli claude 切换回来时，会自动使用 claude-opus-4-8
"~해줘" 提示：说"클로드는 항상 오퍼스 써줘"将 Opus 固定到 Claude，或"플러시 초기화해줘"清除所有固定。您也可以说"제미나이 모델 고정해줘 프로로"将 Gemini 固定到 Pro。

常见工作流

成本优化设置

为日常任务使用轻量模型，并固定一个强力模型以备需要时使用：

# Default to Opus 4.8 for strongest Claude work
/model claude-opus-4-8

# Pin Opus for when you switch to heavy tasks
/flush claude claude-opus-4-8

# Set Gemini Flash as fallback for rate limits
/fallback gemini

多提供商弹性配置

通过链式回退确保不间断的服务：

# Primary: Claude, Fallback: Gemini -> Grok -> Codex
/cli claude
/fallback gemini grok codex

# Pin each provider to its best model
/flush claude claude-opus-4-8
/flush gemini gemini-3-flash-preview
/flush grok grok-3

Gemini 深度推理会话

切换到启用思考模式的 Gemini 进行复杂分析：

# Switch to Gemini Pro with thinking
/cli gemini
/model gemini-3-flash-preview
/thought on

# When done, switch back to Claude
/cli claude
/thought off
